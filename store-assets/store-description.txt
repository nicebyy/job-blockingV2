--------------------------------------------------------------------------------
2. 자세한 설명 (Detailed Description - 복사하여 그대로 붙여넣기)
--------------------------------------------------------------------------------
취업과 이직 준비를 방해하는 불필요한 채용 공고와 블랙리스트 기업,
이제 원클릭으로 깔끔하게 정리하고 진짜 원하는 공고만 집중 탐색하세요!

Job Blocking V2는 국내 5대 채용 플랫폼(원티드, 사람인, 잡코리아, 리멤버, 점핏)에서
원치 않는 회사와 공고를 즉시 숨기고, 잡플래닛과 블라인드의 공개 기업 평점을
공고 카드 옆에 실시간 뱃지로 보여주는 올인원 구직 지원 크롬 확장 프로그램입니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✨ 주요 핵심 기능
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 1. 원클릭 [공고숨김] & [회사차단] 플로팅 툴바
• 채용 카드로 마우스를 가져가면 우측 상단에 정제된 플로팅 알약 툴바가 부드럽게 노출됩니다.
• [공고숨김]: 특정 포지션 공고만 즉시 완전 은닉합니다. 동일 회사의 다른 유익한 포지션은 정상 탐색 가능합니다.
• [회사차단]: 해당 기업의 모든 채용 공고를 원클릭으로 일괄 차단합니다.
• 스마트 정규화: '(주)', '주식회사', 공백, 특수문자 등의 표기가 달라도 동일 기업으로 완벽히 인식하여 중복 차단을 원천 방지합니다.
• 공백 없는 자연스러운 재배치(CSS Grid Reflow): 공고가 숨겨진 자리에 어색한 빈칸(Gap)이 생기지 않도록, 뒤의 공고 카드가 자연스럽게 앞으로 당겨져 매끄럽게 정렬됩니다.

⭐ 2. 잡플래닛 & 블라인드 실시간 듀얼 기업 평점 연동
• 지원하는 모든 채용 사이트의 기업명 바로 옆에 [초록색 잡플래닛]과 [빨간색 블라인드] 평점 뱃지를 실시간으로 표시합니다.
• 마우스 호버 시 상세 평점 정보를 확인할 수 있으며, 클릭 시 해당 기업의 리뷰 페이지로 즉시 이동합니다.
• 동명 기업 오표기 방지(Anti-Ambiguity): 동명 기업이 복수로 검색되거나 평점을 특정할 수 없는 경우, 오정보 노출을 방지하기 위해 뱃지를 자동으로 제외합니다.
• 2계층 스마트 캐시(메모리 + 스토리지): 반복 통신을 방지하여 채용 플랫폼의 네트워크 지연 없이 수초 내에 평점을 안전하게 불러옵니다.

🔄 3. 페이지네이션 ➔ 무한 스크롤 자동 변환 & 자동 채우기(Auto-Refill)
• 번호를 일일이 클릭해야 하는 사람인, 잡코리아의 구형 페이지네이션을 스크롤만으로 다음 공고를 계속 불러오는 무한 스크롤로 자동 개조합니다.
• 자동 채우기(Auto-Refill): 차단된 공고가 많아 화면이 텅 비는 경우, 백그라운드에서 다음 페이지 공고를 즉시 긁어와 화면을 유효한 공고로 꽉 채워줍니다 (최대 5페이지 연속 탐색).
• 무한 루프 차단 및 10초 타임아웃 가드를 적용하여 네트워크 지연 시에도 로딩 스피너가 무한히 도는 현상을 방지합니다.

🛡️ 4. 추천·광고·스폰서 프로모션 배너 자동 차단
• 원티드: 상단 '🔥 적극 채용 중인 회사' 광고 슬라이더 자동 숨김
• 사람인: 상단 AI 커리어 배너, 맞춤 추천 공고 캐러셀, 스토어 프로모션 자동 숨김
• 잡코리아: 'TOP 헤드라인 채용관' 및 프로모션 상품 배너 자동 차단
• 리멤버: '프리미엄 대표기업' 섹션 및 상단 대형 광고 캐러셀 배너 자동 숨김
• 점핏: 사이드 윙 배너 및 상단 프로모션 배너 자동 숨김

📊 5. 대시보드 통계 & 2단 카테고리 필터 관리 (Options)
• 팝업 대시보드에서 등록된 [전체 차단 누적 현황]과 [현재 페이지 실시간 차단 건수]를 듀얼 모드로 확인 가능합니다.
• 옵션 페이지에서 차단 목록을 유형별([전체]/[회사]/[공고]/[키워드]) 및 플랫폼별([원티드]/[사람인]/[잡코리아]/[리멤버]/[점핏]) 2단 탭으로 세분화하여 검색 및 관리할 수 있습니다.
• 30일 스마트 만료(TTL): 마감 후 30일이 지난 공고는 스토리지 용량을 차지하지 않도록 백그라운드에서 자동 청소됩니다.
• JSON 차단 목록 백업 및 복원 기능을 제공합니다.
